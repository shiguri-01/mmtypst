# mmtypst

Render [Typst](https://typst.app/) math in the browser with MathML.

`mmtypst` converts standalone Typst math expressions to native MathML in pure
JavaScript, without shipping the full Typst compiler as WASM. It works in
browsers and server-side runtimes including Node.js, Bun, Deno, and edge
runtimes, so it can be used with SSR and SSG too.

## Install

```bash
npm install mmtypst
```

## Usage

Pass a Typst math expression without its surrounding `$` delimiters. The
result is a complete `<math>` element ready for the DOM or server-rendered
HTML.

```ts
import { typstToMathML } from "mmtypst";

const mathml = typstToMathML("x = (-b plus.minus sqrt(b^2 - 4 a c)) / (2 a)");

document.querySelector(".equation")!.innerHTML = mathml;
```

For options, font setup, supported syntax, and limitations, see the
[package README](packages/mmtypst/README.md).

## React

The [`@mmtypst/react`](packages/react/README.md) package provides a `<Math />`
component that renders MathML in React, including SSR:

```tsx
import { Math } from "@mmtypst/react";

<Math source="x^2 + y^2 = z^2" display="block" />;
```

## Solid

The [`@mmtypst/solid`](packages/solid/README.md) package provides the same
`<Math />` API for Solid, with reactive updates and SSR:

```tsx
import { Math } from "@mmtypst/solid";

<Math source="x^2 + y^2 = z^2" display="block" />;
```

## Development

Install dependencies:

```bash
vp install
```

Start the Solid website and playground:

```bash
vp run dev
```

Build the static site to `apps/website/dist`:

```bash
vp run website#build
```

Apply formatting and lint fixes:

```bash
vp check --fix
```

Run all package tests:

```bash
vpr -r test
```

Parser tests read committed expectations generated by Typst; normal tests do
not require the compiler. After changing the corpus or the version in
[`mise.toml`](mise.toml), regenerate and commit the fixtures:

```bash
mise install
mise exec -- vp run mmtypst#update-typst-conformance
```
